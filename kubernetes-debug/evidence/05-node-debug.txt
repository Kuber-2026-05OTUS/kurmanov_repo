### Шаг 5. Отладочный pod для НОДЫ (kubectl debug node/...)
### Дата: 2026-09-06 23:06:10 +05

### Команда:
NODE=$(kubectl get pod nginx-distroless -o jsonpath="{.spec.nodeName}")   # = minikube
kubectl debug node/$NODE -it \
  --image=nicolaka/netshoot:latest --image-pull-policy=IfNotPresent \
  --profile=sysadmin -- /bin/bash

Создан pod: node-debugger-minikube-rvbwr (на ноде minikube, namespace default)

### Чем отличается от эфемерного контейнера:
kubectl debug node/... создаёт ОТДЕЛЬНЫЙ pod на ноде (а не контейнер внутри чужого pod'а).
Он получает hostNetwork/hostPID/hostIPC=true и корневую ФС ноды, примонтированную в /host.
